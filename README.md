# 🍔 MealMate – Online Food Ordering Android App

MealMate is an Android food ordering application built using Kotlin, XML, and Firebase. It allows users to browse food items, manage their cart, place orders, and track their orders.

## ✨ Features

- 🔐 User Registration and Login
- 🍕 Food Catalogue
- 🔍 Food Search and Categories
- 🛒 Shopping Cart
- 🧾 Checkout
- 📦 Order History
- 🚚 Order Tracking
- ❌ Order Cancellation
- 👤 User Profile Management
- ⚙️ Settings
- 🔥 Firebase Authentication
- ☁️ Cloud Firestore Database

## 🛠️ Technologies Used

- Kotlin
- XML
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Gradle

## 📥 Download the App

### [⬇️ Download MealMate v1.0.0](https://github.com/TarangGupta6446/MealMate/releases/latest)

Download the APK from the GitHub Releases page.

**Installation:**
1. Download the APK to your Android phone.
2. Open the downloaded file.
3. Allow installation from this source if Android requests permission.
4. Install and launch MealMate.

**Note:** This is a debug build intended for testing. Online features require a correctly configured Firebase project.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open it in Android Studio.
3. Create your own Firebase project.
4. Register an Android app using the package name `com.example.mealmate`.
5. Download your Firebase configuration file, `google-services.json`.
6. Place it inside the project's `app` folder.
7. Enable Email/Password authentication in Firebase Authentication.
8. Configure Cloud Firestore and its security rules.
9. Sync Gradle.
10. Run the app on an Android device or emulator.

## 🔐 Security

Firebase configuration is not included in this repository. Configure your own Firebase project before running the application.
