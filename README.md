# 🍔 MealMate - Online Food Ordering App

MealMate is an Android application built to provide a convenient food ordering experience. Users can browse food items, add food to their cart, place orders, track order statuses, and manage their profiles.

## ✨ Features

- User Registration and Login
- Browse Food Items
- Food Search and Categories
- Shopping Cart
- Checkout
- Order History
- Order Tracking
- Order Cancellation
- User Profile Management
- Settings
- Firebase Authentication
- Cloud Firestore Database

## 🛠️ Technologies Used

- Kotlin
- XML
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Gradle

## 🚀 How to Set Up the Project

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Create your own project in the Firebase Console.
4. Register an Android app using the package name `com.example.mealmate`.
5. Download your Firebase configuration file named `google-services.json`.
6. Place the file inside the project's `app` folder.
7. Enable Email/Password authentication in Firebase Authentication.
8. Configure Cloud Firestore and its security rules.
9. Sync the project with Gradle.
10. Run the app on an Android device or emulator.

## 🔐 Security

This project requires Firebase configuration to run its online features. Configure your own Firebase project and use appropriate Firestore security rules before running the application.
